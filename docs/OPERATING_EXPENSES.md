# 영업비용 관리

## 데이터베이스 적용
기존 DB에 migration 12까지 적용되어 있어야 합니다. `database/13_operating_expenses.sql`을 한 번 실행합니다. 이미 적용한 migration 1~12는 다시 실행하지 마세요.

## 사용 방법
1. 점주 또는 매니저로 로그인하고 메인 화면에서 **영업비용 관리**를 엽니다.
2. 조회 시작일/종료일을 선택하고 조회하면 해당 기간의 지출 내역과 정상 지출 합계를 확인할 수 있습니다.
3. 지출일자, 분류, 금액, 결제수단, 사용내역을 입력하고 **지출 등록**을 누릅니다.
4. 잘못 등록한 건은 목록에서 선택하고 **선택 지출 취소**를 누릅니다. 취소된 자료는 삭제되지 않고 취소 이력으로 보존됩니다.

## 관리 원칙
- 매장(Store)별로 데이터가 분리됩니다.
- 지출 금액은 0보다 커야 합니다.
- 결제수단은 현금/계좌이체/카드/기타로 기록합니다.
- 지출 취소는 상태를 VOID로 변경하고 취소 직원/시각을 기록합니다.
- 취소된 지출은 조회에는 표시되지만 정상 지출 합계에서는 제외됩니다.
- 이 기능은 운영비용 기록이며, 회계 기준의 손익/세무 신고 금액을 자동 산출하는 기능은 아닙니다.

## 테스트 체크리스트
- [ ] 점주/매니저만 메뉴에 접근할 수 있는지 확인
- [ ] 일반 직원에게 영업비용 관리 메뉴가 보이지 않는지 확인
- [ ] 네 가지 결제수단으로 지출 등록
- [ ] 금액 0, 음수, 문자 입력 차단
- [ ] 필수 분류/사용내역 누락 차단
- [ ] 조회기간에 맞는 내역만 표시
- [ ] 정상 지출 합계가 취소 건을 제외하는지 확인
- [ ] 지출 취소 후 취소 상태와 합계가 정확히 반영되는지 확인
- [ ] 다른 매장 데이터가 조회되지 않는지 확인

Delphi 12 Athens Win32 Build All 및 Firebird 5.0 DB 테스트는 개발 PC에서 진행해야 합니다.
