# 기간별 수입·지출 현황

## 기능
점주/매니저가 조회 기간을 지정해 다음 항목을 확인합니다.

- 결제 완료 매출 합계 및 현금/카드 매출
- 정상 등록된 영업비용 합계와 분류별 건수/금액
- 거래처 지급액 합계와 지급수단별 건수/금액
- 수입·지출 차액 = 결제 완료 매출 - 영업비용 - 거래처 지급액
- 요약 및 세부 집계 CSV 내보내기

## 조회 기준
- 매출: POS_ORDER 상태가 PAID이고 POS_PAYMENT 상태가 APPROVED인 결제의 PAID_AT 기준
- 영업비용: POS_OPERATING_EXPENSE 상태 ACTIVE인 건의 EXPENSE_DATE 기준
- 거래처 지급: POS_PURCHASE_PAYMENT의 PAYMENT_DATE 기준
- 조회 종료일은 포함되며, 매장(Store)별로 분리 조회합니다.

## 중요한 회계상 유의사항
화면의 수입·지출 차액은 운영 현황을 빠르게 파악하기 위한 관리용 참고 수치입니다. 재고 매출원가(COGS), 미지급 매입액, 세금, 감가상각, 미수금 및 기간귀속 조정 등을 반영하지 않으므로 회계상 순이익이나 세무 신고용 손익으로 사용하면 안 됩니다. 거래처 지급액은 실제 지급한 금액을 기준으로 하므로 매입 발생액과 다릅니다.

## 테스트 체크리스트
- [ ] 기간 선택 후 매출 합계가 매출 보고서와 일치
- [ ] 현금/카드 매출 구분 확인
- [ ] 취소된 영업비용이 합계에서 제외되는지 확인
- [ ] 분류별 영업비용 건수/금액 확인
- [ ] 거래처 지급일 기준으로 지급 합계가 집계되는지 확인
- [ ] 지급수단별 건수/금액 확인
- [ ] 수입·지출 차액 계산 확인
- [ ] 종료일 당일 데이터가 포함되는지 확인
- [ ] CSV 한글과 금액 확인
- [ ] 점주/매니저만 메뉴 접근 가능
- [ ] 기존 판매/결제/영업마감/재고/구매/미지급금/영업비용 회귀 테스트
