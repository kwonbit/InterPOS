# 전체 재고 이력 조회

재고관리 화면의 **전체 재고 이력** 버튼에서 매장 전체의 재고 변경 내역을 조회합니다.

## 조회 조건
- 시작일과 종료일
- 구분: 전체, 입고, 출고, 실사조정
- 메뉴명 일부 검색

기본 조회 기간은 최근 30일이며, 조회 결과는 최신 일시순 최대 1,000건입니다. 조회 결과 화면의 **CSV 내보내기** 버튼으로 현재 조회된 목록을 UTF-8 CSV 파일로 저장할 수 있습니다.

## 표시 항목
- 처리 일시 및 메뉴명
- 변경 구분과 수량
- 변경 전/후 재고
- 사유 코드 및 비고
- 처리 직원

이 기능은 기존 `POS_STOCK_MOVEMENT` 이력을 읽기만 합니다. 데이터베이스 스키마, 재고 수량, 기존 입고/출고/실사 처리 방식은 변경하지 않습니다.
