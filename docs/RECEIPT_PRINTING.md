# 영수증 프린터 설정 및 테스트

## 1차 지원 장비

- BIXOLON SRP-350PG
- RS-232C 시리얼 통신
- ESC/POS 출력 명령
- 한글 데이터는 Windows CP949 인코딩으로 전송

## 설정 방법

POS 판매 화면 하단의 **프린터 설정** 버튼을 누릅니다.

1. 시리얼 포트 이름을 입력합니다. 예: COM1, COM3
2. 프린터의 DIP 스위치/설정값과 일치하는 통신 속도를 입력합니다.
3. 저장 후 테스트 인쇄를 실행합니다.

통신 속도 선택: 2400, 4800, 9600, 19200, 38400, 57600, 115200 bps

현재 초기값은 COM1 / 9600 bps이며, 시리얼 설정은 실행 파일과 같은 폴더의 `InterPOS.ini`에 저장됩니다.

```ini
[ReceiptPrinter]
Port=COM1
BaudRate=9600
```

현재 초기 구현은 8 data bits, no parity, 1 stop bit, 흐름 제어 없음(기본값)을 사용합니다. 실제 프린터의 DIP 스위치 설정과 맞지 않으면 통신이 되지 않을 수 있습니다. 프린터 전원을 끈 상태에서 DIP 스위치를 확인/변경한 뒤 다시 켜세요.

## 출력 기능

- 결제 완료 후 자동 영수증 출력
- 선택 테이블의 최근 결제 완료 주문 영수증 재출력
- 테스트 인쇄
- 출력 실패 시 결제는 취소하지 않고 오류를 표시하며 재출력을 안내

## 주의 및 검증 항목

- 프린터 포트가 Windows 장치 관리자에 표시되는 COM 포트와 일치해야 합니다.
- COM 포트가 다른 프로그램에서 열려 있으면 출력할 수 없습니다.
- 한글 출력은 SRP-350PG의 한글 지원/에뮬레이션 설정과 실제 장비 펌웨어에 따라 결과가 달라질 수 있으므로 테스트 영수증으로 확인해야 합니다.
- 자동 절단은 프린터에 커터가 장착되어 있고 DIP 설정에서 커터가 활성화된 경우에 동작합니다.
- USB 및 네트워크 프린터는 이후 동일한 영수증 데이터 인터페이스에 별도 출력 드라이버로 추가할 예정입니다.

## 구현 파일

- `src/uReceiptPrinter.pas`: 시리얼 연결, ESC/POS 명령, 영수증 데이터 출력
- `src/uSalesForm.pas`: 프린터 설정, 테스트 인쇄, 결제 후 자동 출력, 재출력
