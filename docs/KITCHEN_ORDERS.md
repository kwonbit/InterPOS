# 주방 주문서 및 주방 주문현황

## 적용 대상

- Firebird 5.0
- InterPOS POS 판매
- 주방 프린터: RS-232C 시리얼 ESC/POS 프린터
- 기본 포트 COM2 / 9600bps (실제 장비 설정과 일치시켜야 함)

## 데이터베이스 적용

기존 DB에 아래 스크립트를 **한 번만** 실행합니다.

1. `database/06_kitchen_orders.sql`

이 스크립트는 주방 주문서 헤더 테이블 `POS_KITCHEN_TICKET`을 만들고, `POS_ORDER_ITEM.KITCHEN_TICKET_ID`로 각 주문 항목을 해당 주문서에 연결합니다. 이미 적용한 스크립트는 다시 실행하지 마세요.

## 동작 방식

- POS에서 주문 저장을 누를 때마다 별도의 주방 주문서 티켓이 생성됩니다.
- 기존 테이블 주문에 추가 주문을 저장해도 기존 주문과 섞이지 않는 새 티켓이 생성됩니다.
- 주문 저장 트랜잭션 안에서 티켓과 주문 항목이 함께 저장됩니다.
- 저장 완료 후 주방 프린터로 해당 티켓만 자동 출력합니다.
- 프린터 출력에 실패해도 POS 주문 저장은 유지됩니다. 주방 주문현황에서 티켓을 선택해 재출력할 수 있습니다.

## 주방 주문현황

메인 화면의 **주방 주문현황**을 엽니다.

- 최근 주방 주문서 최대 100건 표시
- 5초 간격 자동 새로고침 및 수동 새로고침
- 티켓별 메뉴명, 수량, 옵션 확인
- 상태 변경: 접수대기 → 조리시작 → 조리완료
- 주문취소 상태 지원
- 선택한 티켓의 주방 주문서 재출력
- 주방 프린터 포트/통신속도 설정 및 테스트 인쇄

상태는 주방 티켓 단위로 관리하므로 테이블 전체 POS 결제 상태와 분리됩니다.

## 주방 프린터 설정

주방 주문현황 화면의 **주방 프린터 설정**에서 COM 포트와 통신 속도를 입력합니다. 설정은 실행 파일과 같은 폴더의 `InterPOS.ini`에 저장됩니다.

```ini
[KitchenPrinter]
Port=COM2
BaudRate=9600
```

현재 시리얼 출력은 8 data bits, no parity, 1 stop bit를 사용합니다. 프린터의 DIP 스위치/통신 설정과 일치시켜야 합니다.

## 테스트 순서

1. 마이그레이션을 실행한 뒤 InterPOS를 실행합니다.
2. 주방 주문현황에서 주방 프린터 설정과 테스트 인쇄를 확인합니다.
3. POS 판매에서 메뉴와 옵션을 선택하고 주문 저장을 합니다.
4. 주방 프린터에서 티켓이 자동 출력되는지 확인합니다.
5. 주방 주문현황에 새 티켓과 메뉴/수량/옵션이 표시되는지 확인합니다.
6. 접수대기, 조리시작, 조리완료 상태 변경을 확인합니다.
7. 동일 테이블에 추가 주문을 저장하고 새 티켓으로 구분되는지 확인합니다.
8. 티켓을 선택해 재출력 기능을 확인합니다.
