# 돈통(Cash Drawer) 설정

## 동작 방식
- 돈통은 영수증 프린터의 DK 커넥터에 연결합니다.
- 현금 결제가 완료된 뒤 ESC/POS `ESC p` 펄스 명령을 영수증 프린터의 시리얼 포트로 전송합니다.
- 카드 결제에서는 돈통을 열지 않습니다.
- 기능은 기본 비활성화이며, 설정이 없으면 기존 결제 흐름에 영향을 주지 않습니다.
- 돈통 열기 실패는 경고만 표시합니다. 이미 완료된 결제는 취소하거나 롤백하지 않습니다.

## InterPOS.ini 설정

실행 파일과 같은 폴더의 `InterPOS.ini`에 다음 항목을 추가합니다.

```ini
[CashDrawer]
Enabled=Y
Port=COM1
BaudRate=9600
Pin=0
PulseOn=25
PulseOff=250
```

| 항목 | 설명 |
|---|---|
| Enabled | Y이면 현금 결제 후 자동 열기, N이면 사용 안 함 |
| Port | 돈통이 연결된 영수증 프린터의 COM 포트 |
| BaudRate | 프린터 시리얼 통신 속도 |
| Pin | ESC/POS 돈통 신호 핀: 0 또는 1 |
| PulseOn | 펄스 ON 시간 값(단위 2ms, 1~255) |
| PulseOff | 펄스 OFF 시간 값(단위 2ms, 1~255) |

기본값은 비활성화입니다. 프린터 제조사/모델에 따라 지원하는 펄스 핀과 시간이 다를 수 있으므로 장비 설명서를 확인한 뒤 설정하세요.

## 테스트
1. 돈통을 프린터의 DK 포트에 연결하고 프린터 전원을 켭니다.
2. Windows 장치 관리자에서 프린터 COM 포트와 통신 속도를 확인합니다.
3. `Enabled=Y`로 설정하고 저장합니다.
4. 현금 결제를 완료해 돈통이 열리는지 확인합니다.
5. 카드 결제에서는 돈통이 열리지 않는지 확인합니다.
6. `Enabled=N`으로 바꾸면 현금 결제 후에도 돈통이 열리지 않는지 확인합니다.
7. 돈통 연결이 끊긴 상황에서도 결제 자체는 정상 완료되고, 돈통 오류 경고만 표시되는지 확인합니다.

## 구현 파일

- `src/uSalesForm.pas`: 현금 결제 완료 후 돈통 열기 호출
