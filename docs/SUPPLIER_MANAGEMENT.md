# 거래처 관리

거래처 관리는 점주와 매니저 권한으로 접근할 수 있습니다.

## 기능
- 거래처 등록 및 수정
- 사업자등록번호, 담당자, 전화번호, 이메일, 주소, 비고 관리
- 거래처명/사업자번호/전화번호 일부 검색
- 거래처 사용/중지 전환
- 매장(Store ID)별 데이터 분리

거래처는 매입 이력과 연결될 기준 정보입니다. 사용 중지된 거래처도 기존 이력 보존을 위해 삭제하지 않습니다.

## 데이터베이스
기존 운영 DB에 `database/10_supplier_management.sql`을 한 번 실행합니다. 이 스크립트는 `POS_SUPPLIER` 테이블과 전용 시퀀스/인덱스를 추가하며 기존 테이블과 데이터는 변경하지 않습니다.

이미 적용한 migration은 다시 실행하지 마세요.
