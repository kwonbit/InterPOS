# 매출 보고서 CSV 내보내기

## 기능
매출관리 및 영업마감 화면에서 조회한 기간의 매출 요약과 메뉴별 판매 내역을 CSV 파일로 저장합니다.

내보내기 파일에는 다음 정보가 포함됩니다.
- 조회 시작일 및 종료일
- 결제 완료 주문 건수
- 총 매출, 현금 매출, 카드 매출
- 메뉴별 판매 수량 및 매출 금액

## 사용 방법
1. 매출관리 및 영업마감 화면에서 조회 기간을 지정합니다.
2. **매출 조회**를 눌러 최신 결과를 표시합니다.
3. **CSV 내보내기**를 누르고 저장 위치와 파일명을 선택합니다.
4. 저장된 CSV 파일을 Excel 등 스프레드시트 프로그램에서 엽니다.

## 데이터 기준
- 기존 화면과 동일하게 결제 완료(PAID) 주문 및 결제 시각(PAID_AT)을 기준으로 집계합니다.
- 내보내기는 현재 화면에 표시된 조회 결과를 저장하며 DB 데이터나 영업마감 내역을 변경하지 않습니다.
- CSV는 UTF-8 인코딩으로 저장됩니다.
