# 기초정보 관리

## 포함 기능
- 매장별 테이블 등록, 이름/구역 수정, 사용/중지 전환
- 음식 종류 등록/수정 및 사용/중지 전환
- 메뉴 등록/수정, 판매 가격과 설명 관리, 사용/중지 전환
- 메뉴 종류와 메뉴는 현재 매장(StoreId) 범위에서 조회 및 저장
- 점주와 매니저에게만 기초정보 관리 버튼 표시

## DB 변경
기존 `POS_TABLE`, `MENU_CATEGORY`, `MENU_ITEM`은 유지합니다.
`database/03_master_data.sql`은 메뉴 설명/정렬 필드를 추가하고 메뉴 옵션 그룹, 옵션 항목, 메뉴-옵션그룹 연결 테이블을 생성합니다.

기존 데이터베이스에 적용하는 변경 스크립트이므로 `01_schema.sql`로 새 DB를 만든 다음 `02_employee_login_indexes.sql`, `03_master_data.sql` 순서로 실행합니다. 이미 적용한 스크립트를 다시 실행하면 객체 중복 오류가 발생할 수 있습니다.

## 현재 화면 사용 방법
1. 로그인 후 테이블 관리 또는 메뉴 관리 버튼을 선택합니다.
2. 테이블 관리 탭에서 테이블을 등록/수정하고 사용 상태를 전환합니다.
3. 음식 종류 탭에서 메뉴 분류를 먼저 등록합니다.
4. 음식 메뉴 탭에서 메뉴를 등록합니다. 메뉴 등록/수정 시 음식 종류 번호는 음식 종류 탭의 종류 번호를 입력합니다.
5. 사용 상태 전환은 데이터를 삭제하지 않고 ACTIVE_YN 값을 변경합니다.
