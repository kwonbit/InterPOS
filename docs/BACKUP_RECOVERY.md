# 데이터베이스 백업 및 복구 검증

## 기능
- 점주(OWNER) 계정만 메인 화면의 **데이터 백업 / 복구 검증** 메뉴를 사용할 수 있습니다.
- Firebird `gbak`를 이용해 온라인 논리 백업 파일(`.fbk`)을 생성합니다.
- 백업 파일을 선택해 별도 이름의 검증용 데이터베이스로 복구할 수 있습니다.
- 복구 검증은 운영 DB 경로를 덮어쓰지 않습니다. 검증 DB는 운영 DB와 같은 서버/폴더에 `_RESTORE_TEST_날짜시간` 접미사로 생성됩니다.

## 설정
실행 파일 옆 `InterPOS.ini`에 다음 항목을 설정합니다.

```ini
[Backup]
GbakPath=C:\Program Files\Firebird\Firebird_5_0\gbak.exe
BackupFolder=C:\InterPOS\backup
```

- `GbakPath`: Firebird 5.0 설치 폴더의 `gbak.exe` 전체 경로
- `BackupFolder`: 백업 파일을 저장할 폴더. 실행 계정에 쓰기 권한이 있어야 합니다.
- 설정이 없으면 위 경로를 기본값으로 사용합니다.
- `ScheduleEnabled`: 매일 자동 백업 사용 여부 (`True`/`False`).
- `ScheduleTime`: Windows 현지 시간 기준 매일 실행 시각 (`HH:MM`).
- `RetentionDays`: 자동 보관 기간(일). 기본값은 30일이며, 1~3650일을 설정할 수 있습니다.
- Firebird 서버가 원격인 경우, 백업 파일은 POS 프로그램이 실행되는 PC에 저장되지만 복구 검증용 DB 파일은 Firebird 서버가 접근할 수 있는 DB 서버의 경로에 생성됩니다.

## 예약 백업 설정
1. 점주 계정으로 백업 화면을 엽니다.
2. **매일 자동 백업 사용**을 선택하고 실행 시간과 보관 기간을 입력합니다.
3. **예약 백업 설정 저장**을 누릅니다. Windows 작업 스케줄러에 `InterPOS_DailyBackup` 작업이 등록됩니다.
4. 작업은 Windows `SYSTEM` 계정으로 실행되므로 InterPOS 프로그램이 종료되어 있어도 백업됩니다. 작업 등록 시 관리자 권한이 필요합니다.
5. 예약을 중지하려면 자동 백업 체크를 해제하고 저장합니다.
6. 실행 파일 옆 `InterPOS.ini`의 DB 접속 정보가 예약 실행 계정에서 읽을 수 있어야 하며, 백업 폴더에 `SYSTEM` 계정 쓰기 권한이 있어야 합니다. 네트워크 드라이브 대신 서버/PC의 로컬 절대 경로를 권장합니다.

예약 실행은 `InterPOS.exe /backup` 명령으로 동작합니다. Windows 작업 스케줄러에서 작업 기록과 마지막 실행 결과를 확인할 수 있습니다. 성공/실패 내역은 `BackupFolder`의 `scheduled-backup.log`에 기록됩니다. 로그에는 DB 비밀번호를 기록하지 않습니다.

## 사용 방법
1. 점주 계정으로 로그인합니다.
2. 메인 화면에서 **데이터 백업 / 복구 검증**을 선택합니다.
3. **지금 백업하기**를 누릅니다. 날짜/시간이 포함된 새 `.fbk` 파일이 생성됩니다.
4. 복구 검증을 하려면 **백업 복구 검증**을 누르고 백업 파일을 선택합니다.
5. 표시되는 검증용 DB 경로를 확인하고 진행합니다.
6. 성공 메시지와 로그를 확인합니다.

## 안전 주의사항
- 복구 검증은 운영 DB를 덮어쓰지 않지만, 검증용 DB 파일이 서버에 남습니다. 검증 후 Firebird 서버에서 해당 파일을 확인하고 필요 시 정리하세요.
- 복구 검증용 DB를 운영 DB 경로와 같게 지정하지 마세요. 프로그램은 별도 경로를 자동 생성합니다.
- 백업 파일에는 고객/매출/직원 정보가 포함될 수 있습니다. 접근 권한을 제한하고 암호화된 저장장치 또는 별도 장소에 보관하세요.
- 백업 파일을 생성하는 것만으로 백업 정책이 완성되는 것은 아닙니다. 정기적인 외부 저장소 복사와 실제 복구 테스트를 운영 절차에 포함하세요.
- 예약 백업은 Windows 작업 스케줄러에 등록된 PC에서 실행됩니다. Firebird DB 서버가 원격이면 백업 파일은 예약 작업이 실행되는 POS PC에 저장됩니다.
- 오래된 백업 정리는 `INTERPOS_*.fbk` 패턴의 파일에만 적용됩니다. 다른 이름의 파일은 삭제하지 않습니다.
- 작업 스케줄러 등록은 관리자 권한이 필요합니다. 예약 실행은 `SYSTEM` 계정이므로 백업 폴더 권한을 확인하세요.
