# InterPOS 아키텍처 초안

## 목표
단일 매장부터 다중 단말 환경까지 확장 가능한 Windows 음식점 POS를 구성합니다.

## 계층
1. Presentation: Delphi VCL 폼 및 프레임
2. Application: 판매/주문/결제/마감 유스케이스 서비스
3. Domain: 주문, 메뉴, 테이블, 결제 등 업무 규칙
4. Infrastructure: FireDAC 저장소, Firebird SQL, 프린터/주변기기 어댑터

## 주요 업무 모듈
- POS 판매: 메뉴 선택, 옵션, 수량, 할인, 주문 저장
- 테이블: 착석/이동/합석/분리 및 테이블별 주문 조회
- 주문: 접수, 조리, 제공, 취소 상태 관리
- 결제: 현금/카드/복합 결제, 부분 취소 및 영수증
- 주방: 주방 프린터 및 KDS 연동
- 운영: 메뉴/직원/권한/매출/마감/환경 설정

## 데이터 원칙
- 주문 품목에는 판매 시점의 메뉴명과 단가를 스냅샷으로 저장합니다.
- 주문/결제/취소는 트랜잭션으로 처리합니다.
- 금액은 부동소수점이 아닌 NUMERIC 타입을 사용합니다.
- 실거래 데이터의 삭제보다 상태 변경과 감사 로그를 우선합니다.

## 개발 순서
1. 프로젝트/DB 연결 기반
2. 메뉴 및 테이블 관리
3. POS 판매와 주문 저장
4. 결제/영수증
5. 주방 프린터 및 KDS
6. 매출 조회/마감/권한/운영 안정화
