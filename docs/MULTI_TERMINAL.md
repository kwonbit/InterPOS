# 다중 POS 단말 주문 동시성

## 현재 구조
- 모든 단말은 동일한 Firebird Server의 동일한 데이터베이스에 TCP/IP로 접속해야 합니다.
- 단말별 설정은 실행 파일 옆 `InterPOS.ini`의 `[POS]` 항목에서 지정합니다.
- `StoreId`는 매장 ID, `TerminalId`는 `POS_TERMINAL.TERMINAL_ID`에 등록된 고유 단말 ID입니다.
- 서로 다른 PC에서 같은 `TerminalId`를 사용하면 안 됩니다. 기본값은 1이므로 추가 단말 설치 시 반드시 변경해야 합니다.

예시:

```ini
[Database]
Server=192.168.0.10
Port=3050
Database=C:\InterPOS\data\INTERPOS.FDB
UserName=SYSDBA
Password=...

[POS]
StoreId=1
TerminalId=2
```

## 이번 보완
테이블 주문 저장은 트랜잭션 안에서 해당 `POS_TABLE` 행을 `WITH LOCK`으로 먼저 잠급니다. 이 잠금은 진행 중 주문이 아직 없는 경우에도 같은 테이블에 대한 신규 주문 생성을 단말 간 순차 처리합니다. 잠금 획득 후 진행 중 주문을 다시 조회하므로 두 단말이 동시에 신규 주문을 만들 가능성을 줄입니다.

주문/주문품목/주방티켓의 ID는 Firebird sequence로 발급하므로 여러 단말이 공유해도 ID가 중복되지 않습니다.

## 실제 다중 단말 테스트
1. Firebird 서버 한 대와 데이터베이스 한 개를 준비합니다.
2. 단말 A와 B의 `Server`, `Database`, `StoreId`를 동일하게 설정합니다.
3. `POS_TERMINAL`에 등록된 서로 다른 `TerminalId`를 각 단말에 설정합니다.
4. 양쪽 단말에서 서로 다른 테이블에 주문을 저장하고, 주방 주문현황에서 두 주문이 모두 확인되는지 확인합니다.
5. 양쪽 단말에서 같은 빈 테이블을 거의 동시에 선택하고 각각 주문 저장을 실행합니다. 두 번째 저장은 첫 번째 트랜잭션이 끝난 뒤 진행 중 주문을 찾아 기존 주문에 추가되어야 하며, 같은 테이블에 OPEN 주문이 두 개 생기면 안 됩니다.
6. 두 단말의 결제 및 영업 개점/마감이 각각 올바른 단말 ID로 기록되는지 확인합니다.

## 주의
- 여러 PC가 각자 로컬 데이터베이스 파일을 사용하는 구성은 다중 단말 공유 구성이 아닙니다.
- 운영 전에는 서버 방화벽에서 Firebird 포트(기본 3050)를 허용하고, 정기 백업과 복구 테스트를 준비해야 합니다.
- 이번 변경은 테이블 주문 생성 동시성에 대한 보완입니다. 실제 두 대 이상의 PC와 Firebird 서버에서 위 테스트를 완료해야 운영 적용할 수 있습니다.
