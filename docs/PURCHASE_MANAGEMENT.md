# 구매관리 및 입고처리

## 적용 환경
- Delphi 12 Athens / VCL / FireDAC
- Firebird 5.0
- 기존 InterPOS 데이터베이스

## 데이터베이스 마이그레이션
기존 운영 DB에 이미 migration 11~14가 적용되어 있다면 `database/15_ingredient_purchasing.sql`을 한 번 실행합니다. 이 스크립트는 원재료 구매 상세 테이블과 시퀀스/인덱스만 추가하며, 기존 구매 헤더와 거래 데이터는 변경하지 않습니다. 빈 DB를 처음 구성하는 경우에는 migration 11부터 15까지 순서대로 실행합니다.

이미 적용한 migration은 다시 실행하지 마세요.

## 구매 등록
1. 점주 또는 매니저 계정으로 로그인하고 **구매관리 / 입고처리**를 엽니다.
2. **구매 등록**에서 사용 중인 거래처와 구매일자를 선택합니다.
3. 재고관리 사용 설정이 된 메뉴를 품목으로 추가하고 수량과 매입 단가를 입력합니다.
4. 저장하면 구매 상태가 **작성중**으로 저장됩니다. 이 시점에는 현재고가 변경되지 않습니다.

## 원재료 구매 등록
1. 메인 화면에서 **원재료 구매 등록**을 엽니다.
2. 거래처, 구매일자, 비고를 입력합니다.
3. 원재료와 수량, 해당 원재료 단위 기준의 매입 단가를 입력하고 구매 품목을 추가합니다.
4. 저장하면 기존 `POS_PURCHASE` 구매 헤더에 작성중 상태로 저장됩니다. 따라서 기존 거래처 매입현황/미지급금 화면에 동일하게 반영되며, 기존 지급 등록 기능을 사용할 수 있습니다.
5. 원재료 구매 상세는 `POS_INGREDIENT_PURCHASE_ITEM`에 저장되고, 기존 메뉴 구매 상세 `POS_PURCHASE_ITEM`과 분리 보관됩니다.

## 입고 확정
- 작성중 구매를 선택하고 **입고 확정**을 누르면 구매 품목의 재고가 증가합니다.
- 메뉴 구매는 기존 `MENU_ITEM` 재고와 `POS_STOCK_MOVEMENT` 이력을 갱신합니다.
- 원재료 구매는 `POS_INGREDIENT.STOCK_QTY`를 증가시키고, 기존 현재고/이동평균 단가와 입고 수량/매입 단가를 반영해 이동평균 단가를 계산합니다.
- 원재료 입고는 `POS_INGREDIENT_MOVEMENT`에 IN 이력과 구매 참조번호를 기록합니다.
- 재고 및 이력 저장, 구매 상태 변경은 하나의 Firebird 트랜잭션으로 처리됩니다.
- 중복 입고 확정은 상태 잠금/검사로 차단합니다.
- 품목 메뉴가 재고관리 미사용 상태이면 입고를 확정하지 않습니다.

## 구매 취소
- 작성중 구매는 재고 변경 없이 취소됩니다.
- 입고 완료 구매는 취소 시 메뉴 또는 원재료 구매 수량만큼 해당 재고를 차감하고 취소 출고 이력을 기록합니다.
- 원재료 구매 취소 후 현재고가 0이면 이동평균 단가도 0으로 초기화합니다. 재고가 남으면 기존 이동평균 단가를 유지합니다.
- 현재고가 취소 수량보다 부족하면 전체 취소 트랜잭션을 롤백하고 구매 상태도 유지합니다.
- 취소된 구매는 다시 입고하거나 취소할 수 없습니다.

## 구매 내역
- 구매일자, 거래처, 상태, 총 구매금액, 등록 직원과 품목 상세를 조회합니다.
- 상태별 필터 및 거래처명 검색을 지원합니다.
- 구매 품목과 공급처는 매장별로 관리됩니다.
