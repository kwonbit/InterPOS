# 원재료 입출고 현황 및 분석

## 기능
- 조회 시작일과 종료일 지정
- 전체 원재료 또는 특정 원재료 선택
- 입고(IN), 사용/출고(OUT), 재고조정(ADJUST) 구분 조회
- 기간 내 입고·사용/출고 수량 및 건수, 재고조정 증가·감소 수량과 건수 표시
- 재고조정 상세 수량은 증가(+)·감소(-) 방향을 표시
- 처리 일시, 원재료, 단위, 구분, 수량, 변경 전·후 재고, 단가, 사유, 담당자 상세 조회
- 현재 조회 결과를 UTF-8 CSV로 저장
- 점주 및 매니저 권한으로 접근

## 데이터 기준
기존 `POS_INGREDIENT_MOVEMENT` 이력을 조회합니다.
- 구매 입고 확정: `IN`
- POS 판매 레시피 자동 차감 및 구매 입고 취소: `OUT`
- 재고 실사 조정: `ADJUST`

조회 기간은 시작일 00:00부터 종료일 다음 날 00:00 직전까지입니다. 매장별 데이터만 조회하며, 재고 수량이나 이동 이력을 변경하지 않습니다.

## 적용 및 확인
이번 기능은 조회 전용으로 기존 데이터베이스 구조를 사용하므로 신규 DB 마이그레이션은 없습니다.

1. GitHub PR 브랜치를 내려받아 Delphi 12에서 `src/InterPOS.dpr`을 엽니다.
2. Win32 / Build All로 컴파일합니다.
3. 점주 또는 매니저로 로그인하고 메인 화면의 **원재료 입출고 현황 / 분석**을 실행합니다.
4. 입고가 있었던 기간, POS 판매가 있었던 기간, 재고 실사 조정이 있었던 기간을 각각 조회합니다.
5. 특정 원재료와 구분 필터가 정확히 적용되는지 확인합니다.
6. CSV 내보내기 후 Excel에서 한글, 날짜, 수량, 단가가 정상 표시되는지 확인합니다.

## 주의
- 이 화면은 이동 이력에 기록된 수량을 집계합니다. 재고의 현재 잔액은 원재료 관리 화면의 현재고를 기준으로 확인합니다.
- 과거 이력이 없는 초기 재고는 이동 내역에 표시되지 않습니다.
