# 거래처 매입현황 및 미지급금 관리

## 적용 환경
- Delphi 12 Athens / VCL / FireDAC
- Firebird 5.0
- 구매관리 migration 11 적용 완료 데이터베이스

## 데이터베이스 적용
기존 운영 DB에 `database/12_supplier_payables.sql`을 한 번 실행합니다. 이 스크립트는 구매 지급 이력 테이블과 시퀀스/인덱스만 추가합니다. 기존 구매·재고 데이터는 변경하지 않습니다.

이미 적용한 migration은 다시 실행하지 마세요.

## 매입현황 조회
1. 점주 또는 매니저로 로그인하고 **거래처 매입현황 / 미지급금**을 엽니다.
2. 입고 완료된 구매 건별로 구매일자, 거래처, 매입금액, 누적 지급액, 미지급 잔액을 확인합니다.
3. 상단 요약에서 전체 입고 매입 합계, 지급 합계, 미지급 잔액을 확인합니다.
4. 거래처명으로 검색할 수 있습니다.
5. 구매 건을 선택하면 해당 구매 건의 지급 이력이 아래에 표시됩니다.

작성중 또는 취소된 구매는 매입채무 집계에서 제외합니다. 미지급 잔액이 0인 구매 건은 미지급 목록에서 제외되지만 전체 요약에는 포함됩니다.

## 지급 등록
1. 미지급 구매 건을 선택하고 **지급 등록**을 누릅니다.
2. 지급 금액을 입력합니다. 일부 금액만 지급하는 분할 지급을 지원합니다.
3. 지급 수단을 `CASH`, `BANK`, `CARD`, `OTHER` 중 입력합니다.
4. 필요하면 비고를 입력합니다.
5. 저장 후 누적 지급액과 미지급 잔액이 자동으로 다시 계산됩니다.

지급 금액은 0보다 커야 하며 미지급 잔액을 초과할 수 없습니다. 구매 헤더를 트랜잭션에서 잠근 뒤 잔액을 재검증하므로 같은 구매 건에 대한 동시 지급으로 초과 지급되는 것을 방지합니다.

## 구매 취소 제한
지급 내역이 한 건이라도 등록된 입고 구매는 구매관리 화면에서 취소할 수 없습니다. 지급 내역과 매입채무가 먼저 정산되어야 재고 역처리와 구매 취소를 진행할 수 있습니다. 지급 이력은 감사 추적을 위해 이 화면에서 수정/삭제하지 않습니다.
