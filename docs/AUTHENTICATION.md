# 로그인 및 직원 권한

## 최초 실행
1. Firebird 데이터베이스에 `database/01_schema.sql`을 실행합니다.
2. `database/02_employee_login_indexes.sql`을 실행합니다.
3. `InterPOS.ini`의 데이터베이스 접속 정보와 `[POS] StoreId`를 설정합니다.
4. InterPOS를 실행하면 해당 매장에 활성 직원이 없을 때 최초 점주 등록 화면이 표시됩니다.
5. 매장명, 점주명, 로그인 ID, 8자 이상의 비밀번호를 등록합니다.

## 비밀번호 저장
- 비밀번호 원문은 DB에 저장하지 않습니다.
- Windows CNG의 PBKDF2-HMAC-SHA256을 사용합니다.
- 반복 횟수는 120,000회이며, 계정마다 16바이트 난수를 salt로 사용합니다.
- DB의 `EMPLOYEE.PASSWORD_HASH`에는 알고리즘/반복횟수/salt/hash가 저장됩니다.
- Windows 10/11의 `bcrypt.dll`을 사용합니다.

## 역할
| 역할 코드 | 화면/기능 |
|---|---|
| OWNER | 모든 메뉴 및 직원 계정 관리 |
| MANAGER | POS/테이블/메뉴 관리, 일반 직원 계정 관리 |
| STAFF | POS 판매 및 테이블 관리 |

매니저는 일반 직원(STAFF)만 등록·비밀번호 변경·사용 중지할 수 있습니다. 점주 계정은 직원 관리 화면에서 직접 사용 중지할 수 없도록 제한합니다. 로그인 화면은 `ACTIVE_YN='Y'`인 계정만 허용합니다.

## 운영 보안
- SYSDBA 계정을 POS 클라이언트의 상시 접속 계정으로 사용하지 말고, 운영용 Firebird 계정을 별도로 생성해 최소 권한을 부여하세요.
- `InterPOS.ini`는 실행 파일과 함께 배포하지 말고 매장 단말기별로 안전하게 관리하세요.
- 매장별 직원 로그인 ID는 고유해야 하며, 마이그레이션 스크립트가 이를 보장합니다.
