# OKPOS 스타일 POS 판매 화면

## 화면 구성
- 상단: 테이블 선택과 선택 테이블의 진행 중 주문 상태
- 좌측: 음식 종류(카테고리) 버튼과 메뉴 판매터치키
- 우측: 주문 상품 목록, 단가/수량/금액, 수량 증감 및 선택 삭제
- 우측 하단: 주문 합계, 주문 저장, 프린터 설정, 영수증 재출력, 결제

## 기존 기능 보존
이번 변경은 POS 판매 화면의 배치와 터치 조작 크기를 조정하는 UI 변경이다.
기존 데이터베이스 구조 및 주문/결제 처리 코드는 변경하지 않는다.
테이블별 추가 주문, 메뉴 옵션 및 옵션 추가금액, 주방 주문서 생성,
현금/카드 결제, 영수증 출력, 현금 돈통 제어, 메뉴 재고 및 레시피 원재료 자동 차감은
기존 처리 흐름을 유지한다.

## 적용 및 확인
1. 최신 feature/okpos-sales-screen 브랜치를 내려받는다.
2. Delphi에서 Win32 Build All을 수행한다.
3. 매장/테이블 선택, 카테고리 전환, 메뉴 선택 및 옵션 선택을 확인한다.
4. 주문 목록에서 수량 +/-, 선택 삭제 및 합계 계산을 확인한다.
5. 주문 저장 후 주방 디스플레이/주방 주문서 연동을 확인한다.
6. 기존 주문에 추가 주문이 정상 반영되는지 확인한다.
7. 현금/카드 결제, 영수증 재출력 및 돈통 제어를 확인한다.
8. 레시피 원재료 재고가 결제 시 정상 차감되는지 확인한다.

DB migration은 없다.
